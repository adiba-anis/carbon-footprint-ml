# 🌱 Personal Carbon Footprint Estimator (Machine Learning)

An interactive Web Application built with Streamlit and Machine Learning (Random Forest Regressor) that estimates an individual's monthly carbon footprint in $kg\ CO_2e$ based on 19 daily lifestyle habits.

## 🚀 Features

- **End-to-End ML Pipeline:** Data preprocessing with `ColumnTransformer` (StandardScaler & OneHotEncoder) and a Random Forest Regressor.
- **Interactive Web Interface:** User-friendly UI built with Streamlit allowing inputs for transport, diet, waste, and energy usage.
- **Currency Adjustment:** Localized input support in Rupees (₹).
- **Instant Insights:** Dynamic feedback categorizing emissions into Low, Moderate, or High footprints.

## 🛠️ Tech Stack

- **Language:** Python
- **Machine Learning:** `scikit-learn`, `pandas`, `numpy`, `joblib`
- **Web Framework:** `Streamlit`
